# PSYC1004 期末复习台

PSYC1004（ANU）期末复习用的单文件网页工具，覆盖 Week 1–12：社会心理学（L1–4）、发展心理学（L5–8）、人格心理学（L9–12）。不用安装，打开 HTML 就能用，可以离线，手机、平板、电脑都可以。

**期末考试**：线下，占总成绩 40%，是 hurdle（必须 ≥50% 才能通过本课）。共 80 道单选：社会心理学 20、发展心理学 30、人格心理学 30。答错不扣分，每题都要作答。

## 怎么用

- **在线**：开启 GitHub Pages 后访问仓库的 Pages 网址（入口是 `index.html`）。
- **离线**：下载 `PSYC1004期末复习.html`，双击打开。

进度保存在浏览器本地（键名 `psyc1004.study.v1`），可以在「备份与资料」里导出、导入。换浏览器或换网址前先导出备份。

## 功能

| 模块 | 内容 |
|---|---|
| 学习总览 | 各周进度、掌握情况、正确率 |
| 知识点复习 | 每个知识点有一句话、比喻、例子、详细解释和易错点，可跨周搜索，能跳回原笔记段落 |
| 研究方法与术语 | 相关、因果、遗传率公式等研究符号的读法 |
| 知识卡 | 闪卡复习，按遗忘间隔安排 |
| 选择题练习 | 逐题练习（即时看解析）、自选计时练习，以及按正式考试结构抽题的 **期末模拟 · 80 题**；可筛选「教授练习题」 |
| 错题集 | 自动收集错题，可重练 |

题目英文为主（与考试一致），可以开启中文对照；每个选项都有中文解析。

## 题库规模

| 部分 | 讲 | 知识点 | 题目 |
|---|---|---|---|
| 社会心理学 | L1–4 | 100 | 148 |
| 发展心理学 | L5–8 | 104 | 151 |
| 人格心理学 | L9–12 | 132 | 201 |

题目包括依据笔记自编的题目，以及教授发布的 48 道期末练习题（`REV-` 开头，标注「教授练习题」）。

## 目录结构

```
复习软件/
├─ index.html             生成物：GitHub Pages 入口
├─ PSYC1004期末复习.html   生成物：本地双击打开（与 index.html 相同）
├─ app.template.html      网页源码（界面与逻辑，不含数据）
├─ build.js               校验题库并内嵌进模板，生成上面两个文件
├─ data/
│  ├─ meta.json                研究符号、公式、内容版本
│  ├─ L01.json … L12.json      每讲的知识点、题目和整理笔记（sourceBlocks）
│  └─ review-*.json            教授期末练习题，构建时并入对应讲
├─ docs/                  内容编写规范
└─ tools/                 一次性脚本（把旧的单文件拆成模板和数据）
```

## 修改后重新生成

需要 Node.js：

```bash
node build.js            # 校验并生成 HTML
node build.js --check    # 只校验
```

校验会检查必填字段、选项数、答案范围、知识点引用和笔记段落编号；有问题会列出具体位置。

## 说明

- L1–L9 的笔记来自课程讲义整理；L10–L12 的笔记依据录课文字稿和 PPT 整理。
- 题目与解析未逐题人工审校，发现错误欢迎提 issue 或直接改 JSON。
- 本工具只用于复习，不是诊断工具。

# 教授期末练习题：收录说明

来源：`E:\PSYC1004\PSYC1004 Final Exam Review Questions - 2026.pdf`（社会心理 10 题、发展心理 14 题、人格心理 24 题，每部分后附答案）。这些题最接近正式考试，要原样收录，并配上和其他题一样完整的中文解析。

## 文件

- 社会 + 发展：`data/review-social-dev.json`
- 人格：`data/review-personality.json`

每个文件是一个数组，每个元素是一道题，字段与 `data/L09.json` 里的 questions 完全一致，另加 `lectureId`（这道题归到哪一讲）：

```json
{
  "lectureId": 2,
  "id": "REV-S04",
  "conceptId": "L2-C07",
  "domain": "social",
  "type": "research",
  "difficulty": "基础",
  "stemEn": "The Minimal Group Paradigm is important because it showed that ________.",
  "optionsEn": ["Prejudice is linked to forming an ingroup identity", "...", "...", "..."],
  "answer": 0,
  "stem": "中文题干",
  "options": ["中文选项A", "...", "...", "..."],
  "explanation": "一两句：为什么选这个，用的是哪个知识点。",
  "optionExplanations": ["A 为什么对/错", "B ...", "C ...", "D ..."],
  "source": "教授期末练习题 · Social 第 4 题；对应 L2 · Minimal group paradigm · [B0021]",
  "origin": "review"
}
```

## 规则

1. **英文原样照抄**：`stemEn`、`optionsEn` 与 PDF 一字不差（只修正明显的排版断行和 PDF 里的错字如「who his high」可保留原样）。选项顺序不变，`answer` 严格按 PDF 答案页（A=0，B=1，C=2，D=3）。
2. **id**：社会 `REV-S01`–`REV-S10`，发展 `REV-D01`–`REV-D14`，人格 `REV-P01`–`REV-P24`，编号等于 PDF 里的题号。
3. **归属**：读对应讲的 `data/L0x.json`（看 concepts 和 sourceBlocks），找到这道题考的知识点，填 `lectureId` 和 `conceptId`；`source` 里引用的 B 编号必须真实存在于那一讲的 sourceBlocks。domain：L1–4 为 social，L5–8 为 developmental，L9–12 为 personality。
4. **中文**：`stem` / `options` 忠实翻译，术语写「中文（English）」；`explanation` 和 `optionExplanations` 用课上的内容讲清楚，文风和 L09 一致，直接、简短。「All of the above」「Both B and C」这类选项，解析要逐一说明每个子项为什么对。
5. `type`：考定义的为 `concept`，考情境套用的为 `application`，考研究发现的为 `research`；`difficulty`：直接回忆为「基础」，情境判断为「应用」，需要区分相近说法的为「辨析」。
6. 如果某题的标准答案和讲义内容看起来有冲突，**以 PDF 答案为准**，在解析里按讲义解释为什么这个答案对，并在最终汇报里列出这道题。

# 核心考点判定（data/learn/core-LNN.json）

目的：让学生先把最可能考的考点过一遍。给「边练边学」每讲的 16 个考点定等级：

| level | 含义 | 显示 |
|---|---|---|
| 1 | 核心：很可能出题，先复习 | 标「核心」 |
| 2 | 一般：课程内容，核心做完再做 | 不标 |
| 3 | 了解：思考题、课堂闲谈、老师明说不考 | 标「了解」 |

## 考试事实

80 道单选：社会心理 L1–4 共 20 题（每讲约 5 题）；发展心理 L5–8 共 30 题（每讲约 7–8 题）；人格心理 L9–12 共 30 题（每讲约 7–8 题）。所以 **L1–4 每讲核心 5–7 个，L5–12 每讲核心 6–9 个**。超出就按证据强弱往下排。

## 证据（按强弱排序）

1. **教授期末练习题**考到的点：`data/review-social-dev.json`、`data/review-personality.json`（看每题的 `lectureId`、`conceptId`、`source`）。被考到的考点一律 level 1。
2. **老师在录课里明说**会考 / 要掌握 / 不考：文字稿在 `E:\PSYC1004\L{n}\...transcript.txt`，用 Grep 搜 `exam`、`test`、`assess`、`need to know`、`won't ask`、`not going to`、`important`、`key`、`remember`。明说会考的 level 1，明说不考的 level 3。
3. **整理笔记里的优先级标记**：`data/LNN.json` 的 `sourceBlocks` 里搜 `STUDY PRIORITY`、`一页速记`、`一句话带走`、`最容易混淆`、`易错`、`ACCURACY`、`自测`、`Revision Question`、`Revision`。出现在这些段落里的点优先 level 1。
4. **课程主线上的经典研究或模型**（有名字、有数字、有结论的）：Asch、Milgram、Sherif、minimal group、Strange Situation、Piaget 阶段、Big Five、CFQ 2.0、UFOV 等。一般 level 1。
5. 讲课的背景铺垫、历史人物生平、方法论补充、课堂问答延伸：level 2 或 3。

判断依据是**考点整体**（看它的 `conceptIds` 和 `rules`），不是单道题。

## 输出格式

每讲一个文件 `data/learn/core-LNN.json`（NN 两位，如 core-L03.json）：

```json
{
  "lectureId": 3,
  "points": {
    "L3-P01": {"level": 1, "why": "教授练习题 S08；笔记一页速记"},
    "L3-P02": {"level": 2, "why": "课程内容，练习题和优先级标记都没提到"},
    "L3-P16": {"level": 3, "why": "老师说思考题不是考试题型"}
  }
}
```

- 本讲 16 个考点**每个都要有**，id 和 `data/learn/LNN.json` 里的一致。
- `why` ≤50 字，写清依据：练习题编号、老师原话大意、笔记里的标记名。

## 校验

在 `E:\PSYC1004\复习软件` 运行 `node build.js --check --only=3`（换成你的讲），不能有报错；如果「提醒」说核心考点数量不在建议范围，调整到范围内，除非证据确实支持更多，那就在汇报里说明。不要改任何别的文件。

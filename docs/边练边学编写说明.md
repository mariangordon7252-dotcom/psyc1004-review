# 边练边学：考点卡片写法（data/learn/LNN.json）

考点卡片在每道题上方显示。读者是第一次学这门课的学生。目标：**读完卡片 10 秒内，知道这个概念是什么、长什么样、在题目里怎么认出来。** 最简洁、最不绕弯子、最形象。

## 每个考点的字段

| 字段 | 写法 | 限制 |
|---|---|---|
| `kp` | 一句大白话说清这个概念**是什么**。专用名词写成「中文（English）」。 | ≤65 字 |
| `analogy` | 一个生活化的比喻，以「像」开头，必须对应概念的关键特征，不是只图好玩。 | ≤40 字 |
| `example` | 一个具体的人或场景，让人一眼看出概念长什么样。优先用笔记里的研究或课堂例子，没有就用日常场景。 | ≤60 字 |
| `rules` | 做题规则，每条固定写成 **题目有「线索词」，就找 答案方向（English）。** 不写「因为」，为什么已经在上面讲过了。 | 1–4 条，每条 ≤45 字 |
| `recap` | 做完要记住的一句话 | ≤40 字 |

`howTo` 已删除，不要再写。

## 改前改后

**改前（L4-P02）**

- kp：有些心理倾向广泛存在，但表现可以不同；社会信念有五种。
- rules：题目有「看情况」，就找社会复杂性；「肯努力」找努力回报；因为关键词直接对号。

问题：没说清是什么，没有英文，规则像密码。

**改后**

```json
{
  "kp": "社会公理（social axioms）是人对「世界怎么运转」的五种基本信念。",
  "analogy": "像五副不同颜色的眼镜，戴上哪副，看到的世界就是哪种颜色。",
  "example": "小李认定「有权的人都会占便宜」，这就是社会愤世（social cynicism）。",
  "rules": [
    "题目有「掌权者占便宜」，就找社会愤世（social cynicism）。",
    "题目有「要看情况」，就找社会复杂性（social complexity）。",
    "题目有「肯努力就有回报」，就找努力回报（reward for application）。",
    "题目有「信仰有益」找灵性（religiosity）；「命中注定」找命运控制（fate control）。"
  ],
  "recap": "五种信念：愤世、复杂、努力、灵性、命运。"

```

## 禁止

- 空话：「有些倾向广泛存在」「这一讲强调……」。
- 元指令：「看到……要追问」「注意区分」。卡片只讲概念和线索，不讲学习方法。
- 名词堆叠：一句话里塞四个术语却没解释任何一个。一个 kp 讲一个概念；如果考点合并了几个概念，kp 讲它们共同的那件事，例子和规则把每个点出来。
- 符号链：不用 `=`、`→`、`+` 代替动词。
- 不编事实：数字、人名、研究结论只能来自原有文字和 `data/LNN.json` 的笔记。
- 字符串里不用英文双引号，引用用「」。
- 英文只加在真正的专用名词后面：理论名、效应名、术语、研究者名、题目选项里会出现的词。普通词不加（不要写「（participants）」「（trials）」「（denominator）」这种）；也不要为了凑英文在规则末尾硬加括号。一个术语在同一张卡片里只需标一次英文。

## 每道题的 `how`

保持现有的两三步不变：

1. 题目有「题干原词」，就找 Y。
2. 因为 Z，所以选 X。
3. 可选：C 不对：因为……

只做一处修改：步骤里出现的专用名词，如果没有英文，补上「（English）」，和卡片里的写法一致。其他字一个都不改。

## 不能动的内容

题目、选项、答案、考点标题、`conceptIds`、顺序，一律不动。

# 边练边学：解题文字写法（data/learn/LNN.json）

这个模式是为了做题，不是读笔记。文字只回答一件事：**题目里有什么，就找什么，为什么。** 能少一个字就少一个字。

## 每个考点的字段

| 字段 | 写法 | 限制 |
|---|---|---|
| `kp` | 一句话说清这个知识点是什么，不列举 | ≤45 字 |
| `rules` | 解题规则，每条固定写成 **题目有「X」，就找 Y；因为 Z。** | 1–4 条，每条 ≤70 字 |
| `recap` | 做完要记住的一句话，可以用口诀 | ≤40 字 |

`howTo` 字段删除。

## 每道题的 `how`

固定 2–3 步，每步 ≤60 字：

1. **题目有「题干原词」，就找 Y。**（「」里必须是题干里真实出现的词，中文或英文都可以）
2. **因为 Z，所以选 X。**（X 是正确选项的字母）
3. 可选，只有确实容易错选时才写：**C 不对：因为……**

## 示例

改前：

- kp：心理学是对心理过程与行为的科学研究；看到「人都这样」要追问哪些人、什么情境（context）。社会心理学研究他人的实际、想象或隐含存在（actual, imagined, implied presence）如何影响思想、感受和行为。
- howTo：选项讲他人影响想法、感受、行为，就是社会心理学；讲特质跨情境是否稳定是人格；讲早期成长变化是发展……

改后：

```json
{
  "kp": "社会心理学研究他人的存在如何影响我们，他人不必真的在场。",
  "rules": [
    "题目有「presence of others」，就找 actual, imagined, implied；因为三种都算。",
    "题目有「独自」但想着别人评价，就找社会影响；因为想象中的他人也算。",
    "题目有「跨时间、跨情境的特质」，就找人格；因为社会心理看他人影响。"
  ],
  "recap": "他人不必在场：实际、想象、隐含都算。"
}
```

题目解析：

```json
"how": [
  "题目有「独自在家」和「想象同学会怎么评价」，就找想象中的他人。",
  "因为他人不在场也能影响人，所以选 D。",
  "C 不对：因为社会助长要别人真的在旁边。"
]
```

## 规则

- **只改 `kp`、`rules`、`recap`、`how`**，删掉 `howTo`。题目、选项、答案、标题、`conceptIds` 和顺序一律不动。
- 不写背景、不写研究过程、不写「值得注意的是」。研究题写成「题目有 Milgram，就找多数人服从到最高电压；因为……」。
- 内容只能来自原来的 `kp` / `howTo` / `how` 和 `data/LNN.json` 的笔记，不增加新的事实或数字。必须考的数字和研究结论要留在规则里。
- 规则要能解决这个考点下的题：每道题都应该能用某条规则解出来。原 `howTo` 里区分易混概念的判断标准不能丢。
- 英文只留术语和题干原词；字符串里不用英文双引号。

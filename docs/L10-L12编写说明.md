## 文件结构（对照 L09.json）

```
{
  "id": 10,
  "title": "中文标题",
  "subtitle": "English title",
  "summary": "一段话：这一讲的主线和复习时该抓什么（与 L09 同风格）",
  "concepts": [ ...24–33 个 ],
  "questions": [ ...36–45 道 ],
  "file": "L10 整理笔记（录课文字稿 + PSYC1004_2026_Personality_Lecture2.pdf）",
  "sourceBlocks": [ {"id": 1, "text": "..."}, ... ],
  "sourceText": "# Lecture 10 · ...\n\n## [B0001] 小标题\n\n正文...\n\n## [B0002] ..."
}
```

### sourceBlocks：这一讲的整理笔记

L10–12 还没有笔记，`sourceBlocks` 就是你整理的笔记：按讲课顺序分成 25–50 块，每块一个小主题（一个研究、一个模型、一组对比），中文为主、关键术语和研究名保留英文，写清"是什么、怎么做的研究、发现了什么、考试要注意什么"。每块第一行是小标题。`sourceText` 由这些块拼成（格式见上，`[B0001]` 四位数编号与 id 对应）。

### concepts（id：`L10-C01`…）

每个知识点的字段和 L09 一样：`title`（中文短标题）、`english`、`oneLine`（一句话）、`analogy`（比喻，以「像」开头）、`simpleExample`、`explanation`（2–4 句讲清楚）、`example`、`pitfall`（最容易错的地方）、`source`（如 `L10 · Psychopathy · [B0006]`，引用的 B 编号必须存在）、`front`（闪卡问题）、`back` 和 `cardBack`（闪卡答案，两者相同）。

### questions（id：`L10-Q01`…）

- `domain` 一律 `"personality"`；`origin` 一律 `"notes"`；`conceptId` 指向本讲的某个知识点。
- `type`：`concept` / `application` / `research`，三类大致各占三分之一；`difficulty`：`基础` / `应用` / `辨析`，约 2 : 3 : 5（和 L1–L9 一致）。
- `stemEn` / `optionsEn` 是英文题干和选项（**考试是英文**，要像教授练习题那样的风格）；`stem` / `options` 是对应的中文。
- `answer` 0–3，四个位置大致均匀分布。
- `explanation`：一两句说清为什么选它；`optionExplanations`：四个选项各一句，说清对或错在哪。
- 每个知识点至少 1 题，重要的 2–3 题；练习题考到的点要有"辨析"题。
